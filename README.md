# MAGD-150
For MAGD 150

Inside are multiple of the lab assignment that were due for **MAGD 150**. 

In lab 2 I crated a picture of balloons. This was the first time we used non-grey scale _colors_ and a bezier curve.

In lab 3 we needed to use the mouse position. I made a box that bounced around the canvas in response to the direction of the cursor.

In lab 4 we used _RNG_ to create a ball that would appear randomly and move off the stage.

In lab 5 we needed to use mouse and keyboard inputs. I created a rough flappy bird that would respond to the space bar and a left click.

In lab 7 we tested with arrays and output numbers that were in the arrays.
